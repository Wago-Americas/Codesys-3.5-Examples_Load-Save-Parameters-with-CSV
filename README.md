## Name

## Description
This video demonstrates how to use the Recipe Manager feature to load and save system parameters in a CODESYS application. This functionality can be used for deployment and configuration scenarios where the PLC program remains unchanged, but different operating configurations need to be loaded by the user.

Typical applications include storing and restoring setpoints, timer values, machine settings, and device configurations. Recipe Manager can also be used as a backup and recovery tool, allowing system parameters to be saved and restored if a PLC needs to be replaced.

By separating configuration data from the application code, users can quickly switch between operating modes, deploy standardized configurations, and reduce downtime during maintenance or system upgrades.
